# Agent Instructions — Template Meta-Project

## Operational Constraints

1. **Metrics are live-introspected.** Never hand-author counts of
   infrastructure modules, pipeline stages, or exemplars. The
   `introspection.py` module reads the live filesystem.
2. **Token injection is mandatory.** Every `${...}` variable in the
   manuscript must be resolved from `metrics.py` at render time.
3. **Figures regenerate from source.** The four architecture figures
   (overview, pipeline, module inventory, comparative matrix) are
   generated by `architecture_viz.py` — never hand-edit the PNGs.
4. **`output/` is disposable.** Regenerate everything: metrics →
   injection → figures → PDF.

## Workflow

Follow the [verification guide](VERIFICATION.md) to prepare the SDK and complete
reference. Run [the project stages](rendering_pipeline.md#generate-evidence-and-hydrate-the-manuscript)
from the standalone project root, then switch to the shared renderer's root
for Stages 03 and 04.

## Critical references

- `docs/manuscript/config.yaml` — publication metadata, token sources.
- `infrastructure/core/pipeline/pipeline.yaml` — stage DAG definition.
- `projects/AGENTS.md` — public exemplar roster (introspected).
